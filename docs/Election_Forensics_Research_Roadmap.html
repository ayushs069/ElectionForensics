Foundations of Election Forensics

Outcome: Understand what election forensics can and cannot establish.

Election forensics is the application of statistical and computational methods to election data to detect patterns that are inconsistent with honest, competitive voting. It does not prove fraud — it identifies statistical anomalies that deviate from what is expected under a null model of fair elections.

What it Can Establish

Whether empirical vote-margin distributions deviate significantly from theoretically expected distributions (like the RVM curve). It quantifies the size and direction of deviations.

What it Cannot Establish

The cause of anomalies. A high fraud score may reflect strategic voting, voter mobilisation, single-party dominance, or data recording errors — not necessarily manipulation.

Anomaly vs. Evidence

An anomaly is a statistically unexpected pattern. Evidence of manipulation requires corroboration from multiple independent sources (field audits, witness testimony, historical records).

Project Application

This project computes fraud scores (mean |z|) for 14 Indian states and flags those exceeding the threshold of 3.0. These are statistical flags, not accusations.

Ethical Principle: The project's fraud-score threshold (|z| > 3.0) is a statistical convention — it means the observed distribution lies more than 3 standard deviations from the RVM prediction. Findings must be reported with appropriate epistemic humility.

Electoral Systems & Election Processes

Outcome: Understand where anomalies can arise in the election pipeline.

This project focuses on First-Past-the-Post (FPTP) elections — the system used in Indian Lok Sabha (parliamentary) elections. Each constituency elects one representative; the candidate with the highest vote total wins regardless of majority.

Constituency Structure

India's 543 Lok Sabha constituencies are grouped by state. The project uses 14 major states, each with ≥ 400 constituency-election records across multiple election cycles (1977–2019).

Key Measured Quantities

vv1 = total valid votes (voter turnout), margin = winner_votes − runner-up_votes, winner_votes, runnerup_votes. These are extracted at constituency level.

Result Aggregation

Candidate-level data (from CLEA and ECI) is aggregated to constituency level using aggregate_to_constituency.py, producing one row per constituency-election observation.

Why FPTP Matters for Forensics

Under FPTP, the vote margin M = winner − runner-up is the key competitive signal. The RVM model is analytically derived for multi-candidate FPTP races, making it directly applicable.

Statistical Election Forensics & the RVM Framework

Outcome: Understand the core quantitative method used to generate fraud scores.

This is the analytical heart of the project. The Random Voting Model (RVM) provides a theoretically derived null distribution for election margins under genuine competition. Deviations from this null distribution are quantified as a forensic fraud score.

5.1 The RVM Null Model

The RVM models a genuinely competitive election: each candidate receives votes drawn from a random multinomial process with uniformly distributed support probabilities. For 3 candidates and large turnout T, the analytical PDF of the specific margin µ = M/T is:

Analytical PDF — Specific Margin (3 candidates, large T)
P(µ) = [(1 − µ)(5 + 7µ)] / [(1 + µ)² (1 + 2µ)²]

Theoretical mean: ⟨µ⟩ ≈ 0.1993 (computed numerically via scipy.integrate.quad)

This formula is implemented in india_rvm_analysis.py → P_mu(mu) and rvm_analysis.py → P_mu(mu).

5.2 The Universal Scaled Distribution F(x)

Rescaling µ by its mean yields the universal function F(x) — a distribution that is theoretically identical for all genuinely competitive elections regardless of country, state, or election size. This is the key universality claim of the project.

Universal Scaled Distribution
x = µ / ⟨µ⟩
F(x) = ⟨µ⟩ · P(µ) where µ = x · ⟨µ⟩

If elections are genuinely competitive, empirical F(x) must collapse onto a single universal curve.
Deviations from this curve → forensic signal.

5.3 RVM Monte Carlo Simulation

Because the analytical F(x) assumes large T, the project validates it with Monte Carlo simulation (RVM ensemble). For each state, 25 independent RVM runs simulate elections using the actual observed turnouts, but with randomly assigned vote shares:

Monte Carlo RVM — one run (rvm_once)
For each constituency i with observed turnout T_i:
1. Draw n_cand = 3 weights w_k ~ Uniform(0, 1)
2. Normalise: p_k = w_k / Σw_k (random support probabilities)
3. Draw votes ~ Multinomial(T_i, p)
4. margin_i = votes[0] − votes[1] (after sorting descending)

The ensemble of 25 runs produces a mean RVM curve and a ±1σ uncertainty band. The actual data is then overlaid on this band.

5.4 Log-Spaced Histograms

Because margin distributions span several orders of magnitude, all distributional plots use log-spaced bins with geometric midpoints:

Log Histogram (log_histogram function)
bins = np.logspace(log10(min), log10(max), n_bins+1)
centers = sqrt(edges[i] · edges[i+1]) ← geometric midpoint
density computed with np.histogram(..., density=True)

5.5 Fraud Score (Mean |z|)

The fraud score measures how much the empirical F(x) deviates from the RVM prediction in units of standard deviations:

Fraud Score Computation (plot_fraud_check)
For each x-grid point x_i:
z_i = |F_empirical(x_i) − F_RVM_mean(x_i)| / (σ_RVM(x_i) + ε)

Fraud Score = mean_i(z_i) over all valid x grid points

Threshold: Fraud Score > 3.0 → state is FLAGGED (⚠)
Statistical Note: The fraud score is a composite z-score, not a p-value. Setting the threshold at 3.0 (≈ p < 0.003 for a single test) is conservative, but there is no multiple-testing correction applied when comparing 14 states simultaneously — an important limitation to disclose in any research paper.

Election Forensic Indicators

Outcome: A collection of measurable forensic indicators used in this project.

Rather than relying on a single statistical trick, a robust analysis uses multiple indicators. This project explicitly implements or discusses the following:

1. Specific Margin Distribution

The distribution of µ = M/T across all constituencies. The key forensic indicator: genuine elections follow P(µ) analytically. Significant deviations indicate manipulation potential.

2. Scaled Margin Distribution

f(M/⟨M⟩) in log-log space. Countries and states with clean elections collapse to the same universal shape. Used in Plot A of the fraud check.

3. Turnout Anomalies

EDA3 plots the distribution of vv1. Unusual spikes or gaps (especially at round numbers) can indicate stuffing or suppression. Log-y scale reveals tail structure.

4. Mean Specific Margin by State

EDA5 (Fig 3) shows ⟨µ⟩ per state vs. the theoretical mean (0.1993). States far below the theoretical mean may have suspiciously narrow margins (proximity to 50%).

5. Temporal Trend in ⟨µ⟩

EDA6 (Fig 2) tracks mean µ over election years. Sudden jumps or drops correlated with political events (e.g. Emergency 1975–77) are highlighted.

6. Winner vs. Runner-up Scatter

EDA10 plots winner_votes vs. runnerup_votes. Points far from the 45° line signal either landslides or near-ties, both of which can indicate different fraud modes.

7. Fraud Score (mean |z|)

The primary composite indicator. Aggregates pointwise deviations of empirical F(x) from the RVM band into a single scalar per state. Threshold: 3.0 σ.

8. Deviation from Theoretical ⟨µ⟩

Computed in compare_world_vs_india.py (Q14): ⟨µ⟩_empirical − ⟨µ⟩_theory. States with large positive deviations have systematically higher-than-theoretical margins.

Note on Benford's Law: Benford's Law (anomalous digit distribution in leading digits of vote counts) is not used in this project. Its applicability to election data is heavily debated: vote counts are bounded (0 to T) and often do not span multiple orders of magnitude, violating the key assumption. The RVM framework is better suited to this dataset.

Spatial Election Forensics

Outcome: Map anomalies geographically; understand spatial clustering.

This project implements spatial analysis at the state level (rather than constituency or polling-station level) due to data aggregation. The following spatial questions are explicitly addressed:

State-Level Clustering

EDA1 and the fraud bar chart (Fig in outputs/) visualise which states cluster as high-fraud-score vs. low-fraud-score, enabling geographic identification of anomaly hotspots.

All-States F(x) Overlay

plot_all_states_Fx() overlays F(x) curves from all 14 states on a single log-log plot. States whose curves diverge from the universal curve are visually identifiable.

World vs. India Comparison

compare_world_vs_india.py provides a cross-national spatial comparison. India's states are positioned relative to world countries on fraud scores and mean µ.

Coverage vs. Mean µ Bubble Map

Q16 in the comparison script creates a bubble plot where position = (n_units, ⟨µ⟩) and bubble size ∝ fraud score — effectively a 3D spatial diagnostic.

Future extensions of this project could incorporate constituency-level shapefiles (from Datameet or ECI GIS portal) to produce choropleth maps of µ or fraud scores, and formal spatial autocorrelation (Moran's I) analysis to test whether high-fraud-score areas cluster geographically.

Machine Learning for Election Forensics

Outcome: Understand how ML complements (not replaces) the statistical RVM approach.

This project does not rely on ML as the primary tool — it uses a theoretically derived statistical model (RVM) as the null hypothesis. ML would complement this in the following ways:

Unsupervised Clustering

K-means or DBSCAN on features [⟨µ⟩, fraud_score, n_units, yr_min] could automatically group states into "suspicious" vs. "clean" clusters without defining a manual threshold.

PCA for Feature Reduction

If additional forensic indicators are added (EDA1–10 metrics, temporal features), PCA could reduce dimensionality and reveal which combinations of indicators drive anomaly flags.

Isolation Forest

Could score each constituency-year record as an anomaly based on its (µ, T, M) tuple. Particularly useful for identifying specific years of anomalous behaviour within a generally clean state.

Autoencoder Anomaly Detection

Train on the F(x) histogram vectors of "known clean" states/countries. States producing high reconstruction error would be flagged — learning the normal pattern automatically.

Important Limitation of ML Here: There is no labeled training set of "definitely fraudulent" elections — the ground truth is unknown. Any supervised approach would require expert-labeled cases. Unsupervised methods are therefore more honest, but their outputs are harder to interpret.

The RVM Monte Carlo simulation itself can be considered a type of generative model: it learns the data-generating process from first principles rather than from examples. This is more defensible in a scientific context.

Advanced Forensic Modelling

Outcome: Move from simple anomaly detection toward statistically defensible inference.

The current project implements a solid baseline. The following extensions represent the frontier of election forensics methodology:

TechniqueHow It Applies to This ProjectBenefit
Mixture ModelsModel the empirical µ distribution as a mixture of a "clean" RVM component and an "anomalous" component. Estimate the anomalous fraction.Provides interpretable fraud proportion estimate rather than a binary flag.
Bayesian ApproachesPlace a prior on the expected mean µ (theoretical RVM); update it with data. The posterior credible interval reveals whether India's observed µ is consistent with honest elections.Handles small samples better; naturally quantifies uncertainty.
Hierarchical ModelsModel state-level µ distributions as draws from an all-India hyperprior. Partially pools information across states — avoids over-fitting rare states.Stable estimates for states with few constituencies.
Sensitivity AnalysisRe-run fraud scoring with n_cand = 2, 4, 5 instead of 3. Check whether flagged states remain flagged across different candidate-count assumptions.Tests robustness of the 3-candidate assumption in RVM.
Robust StatisticsReplace the mean z-score with a trimmed mean or median z-score to reduce sensitivity to extreme histogram bins in the tails of F(x).More robust fraud score less influenced by sparse tail data points.
Synthetic ControlsFor a specific flagged election year in a state, construct a synthetic "control" state from a weighted combination of clean states with similar demographic features.Causal interpretation: what would the margin distribution have looked like without the anomaly?

Digital Election Forensics & Data Integrity

Outcome: Ensure computational reproducibility and distinguish statistical from cybersecurity evidence.

This module covers how data integrity, provenance, and reproducibility are handled in this project — and where the boundaries lie.

Data Provenance

Raw data originates from the Constituency-Level Elections Archive (CLEA) and Election Commission of India (ECI) official results. The data pipeline is: raw CSV → clean_clea_data.py → aggregate_to_constituency.py → processed/finallllllll.csv.

Reproducibility

All random seeds are set explicitly (seed=42 in RVM ensemble). The 25-run ensemble is deterministic given the same seed. Scripts accept command-line arguments for full parameter traceability. Outputs are saved with timestamps in directory names.

Audit Trail

The summary.csv file records for each state: n_units, yr_min, yr_max, mean_T, mean_M, mean_µ, mu_analytical, fraud_score, flagged. This serves as a compact, reviewable audit document.

Statistical vs. Cybersecurity Evidence

A high fraud score in this project means the margin distribution deviates from RVM predictions. This is NOT evidence of hacking, EVM tampering, or server breaches — those would require digital forensic investigation of voting hardware and software logs.

Critical Distinction: Statistical anomalies (what this project detects) and cybersecurity incidents (e.g., EVM vulnerabilities) are entirely separate evidence streams. Do not conflate them. A high fraud score might reflect aggressive genuine voting patterns (e.g., one-party dominance), not digital manipulation.

12.3 Reporting Uncertainty Honestly

  • The ±1σ RVM band in every F(x) plot visualises model uncertainty from the 25-run ensemble.
  • The fraud score threshold of 3.0 is a convention, not a proven detection boundary.
  • States with small n_units (close to the 50-record minimum) have noisier distribution fits and their fraud scores have higher variance.
  • The 3-candidate assumption in P(µ) is a simplification; India regularly has 5–10+ candidates per constituency.
  • No adjustment for multiple testing across 14 states is applied.

12.4 Research Questions Addressed

The project answers the following research questions:

  1. Do Indian parliamentary elections follow the universal RVM margin distribution F(x)?
  2. Which states show statistically significant deviations from the expected distribution?
  3. How do Indian states compare to world countries on the same forensic indicators?
  4. Has the competitive structure of Indian elections (as captured by ⟨µ⟩) changed over time?
  5. Is there evidence of a geographic clustering of anomalous states?
PhD-Level Extension: A publishable extension would replace the 3-candidate analytical P(µ) with a flexible mixture model fitted to the actual candidate-count distribution per constituency. A Bayesian hierarchical version would partially pool information across states. Sensitivity to the minimum-units threshold (currently 50) should be characterised via a robustness table.
